# Contributing to Fuzzy Parser

Thank you for helping improve Fuzzy Parser.

Start with the [contributor guide](docs/contributing.md) for the repository
layout, verification commands, branch policy, and release rules. The
[documentation index](docs/README.md) provides separate paths for users,
application integrators, contributors, and release operators.

Please open an issue before beginning a broad contract or architecture change.
Parser changes must preserve source evidence, report uncertainty honestly, and
remain independent of consumer-specific business rules.
